## 适用范围与证据地位

把本文件用于：

- 汉语语篇的语域、及物性、语气、情态、主位、衔接和小句复合体分析；
- 判断汉语词语、短语、小句或构式是否实现语法隐喻；
- 用本机词典和可核验在线新词语资源固定流行语、新词与新义的语境义；
- 为候选隐喻给出自然的汉语一致式，而不是先翻译成英语再判断；
- 解释汉语零派生、`的`、结果/趋向补语、连动结构、语气词、`是……的`、`有……` 和 `我想/我认为/我觉得……` 等资源；
- 有控制地进行汉英比较。

区分三种证据地位：

1. **来源理论**：杨延宁对汉语系统和汉语语法隐喻的描述。引用时标明其著作和章节。
2. **技能综合**：本文件把书中的描述转化为工作流，并与 Halliday 的重映射观、杨炳钧的 Context-first/AS IF、Full Realization 以及 Li & Yang 的四系统原则结合。
3. **分析推断**：对用户文本的具体解释。不得把分析者的推断写成杨延宁或 Halliday 的原话。

杨延宁书中某些类别比本技能采用的严格识别门槛更宽。发生冲突时，同时报告“杨延宁框架下的候选类别”和“严格识别协议下的判定”，不要悄悄合并两者。

## 汉语分析的基本原则

### 1. 理论范畴与描写范畴分开

保留元功能、层次、级阶、系统与实现等一般理论范畴，但不要把英语的具体描写类别原封不动套到汉语。先问某个意义在汉语中如何组织，再确定其词汇语法实现。

### 2. 从上到下优先，三眼并用

按以下顺序检查重要选择：

1. **从上看**：它在语境和语义层做什么？
2. **从周围看**：同一系统中还有哪些汉语选择？
3. **从下看**：词序、虚词、实词、补语、重叠、语调或书写形式怎样实现该选择？

形式证据不能替代功能证据。例如，无形态变化的动词可以在名词性位置出现，但“零派生”本身不证明语法隐喻。

### 3. 系统先于结构

先确定可选意义，再标注结构。不要因看见某个字词就机械指定过程类型、主位或情态。尤其注意：

- `有` 可能是存在过程、领属关系或不定指引介资源；
- `是` 可能实现识别关系、类别归属或强调；
- `我觉得/我认为` 可能是字面心理过程，也可能使概率或评价显性化；
- `吗/呢/吧/啊` 的功能取决于共同出现的语气形式和语境。

### 4. 汉语内部建立一致式关系

构造一致式时，优先使用自然、语域相容、命题内容尽量相同的汉语表达。不要先构造英语一致式再回译。若找不到自然的汉语对应表达，降低置信度并考虑该单位已词汇化、属于普通名词化/嵌入，或根本没有可证的一致—隐喻关系。

## 汉语小句的三大元功能

### 概念功能：及物性

以六类过程作为初始假设，而不是仅凭中心动词贴标签：

| 过程类型 | 核心经验意义 | 常见参与者 | 汉语诊断重点 |
| --- | --- | --- | --- |
| 物质 | 做、发生、改变 | 动作者、目标等 | 结果或趋向补语可能改变整体过程意义 |
| 心理 | 感觉、认知、情感、意愿 | 感知者、现象 | `看到/听到` 不等同于单纯的 `看/听` |
| 关系 | 归属、属性、识别、领属 | 载体—属性、标记—价值等 | 形容词谓语不必有 `是`；领属 `有` 可属关系过程 |
| 行为 | 生理或心理行为 | 行为者等 | `看、听、笑、哭` 等须结合补语与语境区分心理/物质过程 |
| 言语 | 说、问、命名、符号表达 | 说话者、话语、受话者等 | 可投射话语，也可仅表示言语行为 |
| 存在 | 某物存在或出现 | 存在物 | 存在 `有` 通常只有一个核心参与者；不要把所有 `有` 都判为存在过程 |

执行以下反例检查：

- `天气很热`、`中国很大` 可分析为关系—属性小句，不能因为没有系词而另立过程类型。
- `有人等你` 中的 `有` 可能主要引入不定指的 `人`；不要自动切成独立存在小句。
- `看` 可偏行为，`看到` 可偏心理；分析动词组整体，包括结果和趋向补语。
- 环境成分常由介词短语或副词组实现，多在主要过程前；`得` 字方式补语可在过程后。汉语介词的动词性来源使参与者/环境边界可能呈梯度。

报告时说明：谁被构造成过程的发起者或感知者，哪些时间、原因和施事被省略，以及该选择如何服务语篇目的。不要把及物性缩减为“动词带不带宾语”。

### 人际功能：语气与情态

汉语可区分陈述、疑问和祈使，但不依靠英语式的主语—限定成分倒装。分析时：

1. 先识别语境中的言语功能：给予/求取信息，还是给予/求取物品与服务。
2. 再检查陈述语序、疑问词原位、正反问、句末语气词、祈使标记、否定、称呼和回应可能。
3. 将情态分成命题的概率/通常性与提议的义务/意愿。
4. 记录情态动词、副词、投射小句、评价词和语气词的组合；不要预设只有某一词类能实现情态。

汉语的限定性系统与英语不完全同构：极性和情态资源较明显，而时态常由体、时间成分或语境承担。`能/会/可以` 的能力义与情态的关系有争议；在当前实例中说明是能力、许可、概率还是意愿，不强行归类。

### 语篇功能：主位与信息

把小句开头的语篇出发点分析为主位，但不要机械等同于主语、施事或日常所说的“话题”。

- 主位与主语重合时通常是无标记选择；不重合时说明标记性及其语篇动机。
- 多重主位可包含语篇主位、人际主位和主题主位，例如 `但是，不幸的是，他病了`。
- 汉语疑问词通常原位，疑问小句的主位未必像英语一样移动。
- `的` 字结构和名词化可把复杂意义组织成结构主位，如 `最重要的是速度的改变`；是否构成语法隐喻仍须另行验证。
- 没有语音、重音或明确问答语境时，不要仅凭词序断言已知/新知；主位—述位与已知—新知是不同系统。

## 其他语法单位

### 小句复合体

分析主从关系和扩展/投射，但尊重汉语的实现方式：

- 连接词可省略，语义关系仍可能由顺序、语境或词汇体现；
- 从属小句常位于主句之前；
- 汉语不以英语式关系代词作为关系小句的默认模板；
- 区分投射的言语/思想与扩展的详述、延展、增强。

### 词组

- 汉语名词组中修饰语通常位于中心词之前，`的` 的有无可改变描述性与分类性关系。
- 动词组可包含辅助成分、事件成分、结果/趋向扩展成分；连动结构的界线须结合语义关系判断。
- 形容词可直接作谓语；不要用英语系词结构倒推汉语分析。

## 汉语语法隐喻识别程序

对每个候选项执行以下八步。

### 第一步：固定单位和语境

引用完整小句及必要前后文，确定语域、交际任务和回应潜势。词语脱离语境通常只能作条件性判断。

若候选是流行语、新词或新义，同时读取 [lexical-evidence.md](lexical-evidence.md)：精确查询两部本机词典，保留全部同形义项；本地缺词、空释义或语境义不匹配时再核验在线来源。词典提供的是词汇证据，不能代替下列语法隐喻测试。

### 第二步：说明语义值

先说明候选表达承担的是序列、图形、参与者、过程、性质、环境、连接关系、投射、情态还是言语功能。不要由词类直接反推语义。

### 第三步：构造自然的汉语一致式

给出保持主要意义和语境功能的汉语同义关系项。例如：

- `经济快速发展` → `经济的快速发展`，可测试过程是否被重构成“事物”；
- `伽利略说地球在运动` → `伽利略关于地球运动的说法`，可测试投射是否被重构成名词组；
- `他可能病了` ↔ `有可能他病了` / `我想他病了`，须进一步判断不同实现的取向和语境功能。

一致式不是“更好”的表达，也不必更短。若改写改变施事、时态、极性、情态值或言语功能，说明差异并降低证据力度。

### 第四步：比较语义—语法映射

杨延宁以跨级阶语义范畴描述四条主要路径：扩展、投射、情态和言语功能。检查同一语义是否从较典型的实现级阶转移到另一语法级阶，并明确写出：

`语义值 → 当前实现；语义值 → 一致式实现`

仅有级转移不够；还必须有当前语境中可激活的语义连接和可辩护的一致关系项。

### 第五步：检查汉语零派生和形式资源

汉语动词、形容词和名词之间可能没有显式形态变化，也可能借助 `性、率、度` 或 `的`。因此：

- 后缀、`的` 或名词句法位置只是线索，不是判决；
- 测试原过程、性质或关系意义在当前使用中是否仍然活跃；
- 检查该单位是否已成为普通名称、产品、人物、工具、地点或计量单位；
- 检查是否只是嵌入、关系化或普通词类多功能，而非意义的重新映射。

若候选涉及名物化，且选用 `HALLIDAY_PLUS_YANG_OPERATIONAL`，可按
[gm-decision-protocol.md](gm-decision-protocol.md) 运行汉语 MPP 审慎适配。此处 MPP 及四系统操作化来自 Wen Li 与杨炳钧，不是杨延宁的汉语描写框架。优先同一核心语素，其次明确的名词化/实体化资源，再次是保留核心语素且改动最小的结构同源，最后才使用非形态语义同源。不得为汉语伪造英语式派生层级；`性、度、率、量、感、力、化、行为、过程、现象` 本身不构成 GM 证据。MPP 只是后续操作化的一致关系项选择工具，不能取代跨层重映射。只要汉语候选运行 MPP，就设置 `mpp.crosslinguistic_caution=true` 和 `needs_human_review=true`。

### 第六步：应用类型专门测试

- 概念名词化：先证明语义—词汇语法重映射；若选用 Li–Yang/杨炳钧后续操作化 profile，再应用语义连接、MPP、FRP 和级转移；完整程序见 [gm-decision-protocol.md](gm-decision-protocol.md)。
- 语气隐喻：先比较实际言语功能与典型语气实现；仅在相应扩展 profile 中应用杨炳钧（2019）的 Context-first 和 AS IF。
- 情态隐喻：先定概率、通常性、义务或意愿，再比较主观/客观、显性/隐性取向。
- 极性隐喻：先给直接否定的一致式，再证明否定意义如何被间接重构。
- 所谓语篇隐喻：先排除普通标记主位、衔接变化和概念/人际隐喻的语篇后果。

### 第七步：寻找最强反分析

至少检查一种非隐喻解释：普通多义、词汇化、复合词、嵌入、信息结构选择、礼貌策略、字面心理/关系过程或语境不足。不能通过反例检查时，不给高置信度 `GM`。

### 第八步：给分层判定

在正式 v3 记录中，概念和人际两轴分别使用 `TYPICAL_GM`、`MARGINAL_GM`、`NON_GM`、`INDETERMINATE`，极性另行记录；同时写明置信度和人工复核状态。若杨延宁的宽分类与严格协议不同，可写：

> 杨延宁分类框架下：X 类候选；严格识别协议下：因缺少自然一致式、跨层重映射或语境证据（或在扩展 profile 下未通过适用测试），判为有争议。

## 概念语法隐喻分类

以语义功能转移而不是表面词类作为标签。杨延宁列出的 13 类可作为候选搜索表：

| 编号 | 转移 | 典型分析问题 |
| ---: | --- | --- |
| 1 | 性质 → 事物 | 性质是否成为可指称、可计量、可修饰的参与者？ |
| 2 | 过程 → 事物 | 过程是否被压缩为名词组，时态和参与者是否被背景化？ |
| 3 | 环境 → 事物 | 时间、地点、方式或原因是否被重构为事物？ |
| 4 | 连接关系 → 事物 | 因果、条件等关系是否被事物化？ |
| 5 | 过程 → 性质 | 过程是否成为修饰语或属性？ |
| 6 | 环境 → 性质 | 环境意义是否作为事物的性质实现？ |
| 7 | 连接关系 → 性质 | 关系意义是否成为修饰性资源？ |
| 8 | 环境 → 过程 | 环境意义是否改由过程表达？ |
| 9 | 连接关系 → 过程 | 逻辑关系是否由过程表达？ |
| 10 | 连接关系 → 环境 | 逻辑关系是否压缩为介词/副词性环境？ |
| 11 | 增加事物 | 杨延宁框架中的扩展类；严格协议要求可恢复的一致关系项 |
| 12 | 增加过程 | 杨延宁框架中的扩展类；严格协议要求可恢复的一致关系项 |
| 13 | 事物 → 性质 | 事物意义是否成为分类或描述性修饰语？ |

第 11、12 类在书中被描述为没有直接一致式的类型。这与本技能“必须给出自然一致关系项”的规范门槛存在张力。因此不得仅凭“增加事物/过程”作确定性 GM 判定；应报告为作者模型特定类别，并在严格协议下给出 `有争议` 或其他合适结论。

概念隐喻常形成“综合征”：一个过程名词化后，参与者可能转为修饰语，连接关系可能转为过程、环境或性质。逐项标出主要重映射和伴随重映射，不把整串结构重复计数为多个独立隐喻。

## 人际语法隐喻分类

### 语气隐喻

先确定交际功能，再比较语气形式。书中归纳的汉语候选模式包括：

- 疑问式实现命令：`还不……？`、`……好/行/可以吗？`；
- 陈述式实现命令；
- 疑问式实现陈述：如反问 `难道……？`、`不是……吗？`、`有什么……？`；
- 陈述/投射结构实现提问：`我想知道/了解……`。

这些构式不是脱离语境的隐喻标记。用回应潜势测试：预期的是答案、赞同/反驳、执行/拒绝，还是接受/谢绝？然后给出匹配实际功能的一致式。例如，一个形式疑问句若期待执行而非信息回答，可给祈使一致式并解释礼貌、可协商性和权威的变化。

### 情态隐喻

候选资源包括：

- 投射小句：`我想/我认为/我估计/我觉得……`；
- `是……的`：如 `按时完成任务是可能的`；
- `有……`：如 `有可能他已经走了`、`有必要让他知道`。

先排除字面过程：`我想这件事想了三天` 中的 `想` 不是自动的概率隐喻。再确定情态域与值，并比较更内嵌的汉语实现，如 `他可能病了`、`他应该知道`。书中对不同构式可实现概率、通常性、义务和意愿的分布是其分类模型，不应当作所有语境中的固定词表。

### 句末语气词

`吗、呢、吧、啊` 可参与疑问、协商、缓和、提醒或命令，但单个语气词不证明语气隐喻。必须把语气词、句式、语调（若有）、上下文和回应潜势一起分析。文本没有语音信息时，标明对语调和语气的限制。

## 汉英语法隐喻比较

比较时保持单位和语域可比，并控制以下差异：

- 汉语低屈折、重体貌且可由语境补足时间；不要用英语时态形式作唯一基准。
- 汉语从属小句和环境成分常前置，名词组修饰语通常在中心词前。
- 连动结构、结果补语和趋向补语可承担英语由小句、介词或派生词承担的意义。
- 汉语性质较常以小句谓语实现，不能因英语需要系词或名词化就假设汉语也相同。
- 汉语概念隐喻常没有显性派生标记；英语后缀和汉语零形式都不能单独决定判定。

杨延宁基于其语料报告：汉语概念隐喻的比例低于英语，而人际隐喻相对更高，尤其与 `我觉得/我认为` 等概率表达有关。把这写成“该书语料中的发现”，同时报告语料、语域和计数口径；不要普遍化为汉语和英语的本质差异。

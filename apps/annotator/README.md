# Halliday Lab · 语法隐喻标注平台

面向研究者的 Web 工作台：导入有语境的文本，获得模型提出的标注候选，核验一致式、映射与反证，再导出可追溯的数据。

## 已实现

- React / TypeScript 三栏工作区：项目、原文高亮、证据详情与批量审核；支持重叠跨度和移动端布局。
- Cloudflare Workers 服务端与 D1 数据库：项目、文本及历史版本、框架快照、标注任务、审核历史；操作按登录用户隔离。
- 内置 Halliday GM Schema v3：独立保留概念／人际判断，校验上下文门槛、重映射、中文 MPP 约束及正反证。规则从本仓库公开规范移植，未上传私有文献或词典。
- OpenAI、DeepSeek、Qwen、Anthropic 服务端调用适配器；API Key 仅保留在当前页面内存，随本次请求交给服务端，不写入数据库或本地存储。可改由部署环境注入密钥。
- JSON / XML 框架导入、树形编辑、拖放或键盘调整层级、另存不可变版本。自定义框架使用通用格式；内置 GM 框架才输出正式 v3 记录。
- XLSX 导出与审核列导回；版本冲突时整批不写入。JSON 导出保留当前文本及完整原始机器记录。
- 支持 File System Access API 的浏览器可连接本地工作簿，在页面打开期间每 10 秒同步；冲突、权限或文件锁错误会暂停。其他浏览器使用导出／导入。

## 开始使用

1. 登录工作台，创建项目并导入 UTF-8 TXT；补充来源、语类和语境。
2. 选择内置框架，在模型设置中填写提供商、你账户可用的模型 ID 和 API Key。
3. 运行自动标注，点击原文高亮查看一致式、支持证据、反向检验和完整记录。
4. 在审核面板筛选类别或低自评分实例，确认、排除或修订，再导出。

不配置模型时，可先点击“教学示例”，再点击“载入示例标注”。这些案例是人工构造的回归测试数据，不是模型推理或语料库证据。

## 数据与判断边界

自评分是模型的主观置信等级，**不是经过校准的正确率**。v3 的 HIGH / MEDIUM / LOW 在界面投影为 0.90 / 0.70 / 0.35。默认 80% 只用于提醒，不会自动接受标注。两条判断轴保留在原始记录中；单一界面颜色按概念轴、人际轴、待定、非隐喻的顺序投影。

机器原始 v3 记录保持不变。人工修改类别、一致式或依据，会更新审核视图并保留修改前快照；不能把人工改过的单一类别误当作机器原始理论诊断。下载的 `MachineRecords` 表存原始记录。

本站没有连接私有理论原文和词典；自动结果中的文献、词义和理论依据需要研究者另行核验。网页输入会发送给你选定的模型提供商。没有进行真实付费模型调用或语言学准确率评估；适配器通过受控响应测试，不能据此声称真实模型达到某种准确率。

## 当前边界

| 项目 | 限制 |
| --- | --- |
| 单份保存文本 | 100,000 UTF-16 单元 |
| 单次模型输入 | 6,000 UTF-16 单元，输出最多 80 条 |
| Excel 导出／导入 | 最多 250 条；上传不超过 5 MB |
| 批量审核 | 最多 250 条；队列最多返回 1,000 条，可按文本筛选 |
| 框架 | 最多 200 节点、8 层 |
| 本地文件同步 | 页面打开且文件授权有效时运行，非后台常驻服务 |

完整文档标注跨度使用 UTF-16 `[start,end)`，与浏览器 `slice` 一致；原始 v3 记录在 `record.sentence` 内使用 Unicode 码点。含 emoji 时二者不同，服务端会转换并核对原文。

## 本地开发

需要 Node.js 24（测试使用内置 `node:sqlite`）及 npm。

```bash
npm ci
npm run db:generate  # 仅在修改 schema 后生成新迁移，不重复修改已应用迁移
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_conscious_sue_storm.sql
npm run dev
```

按终端打印的本地 URL 打开。便携开发模式提供仅限本地的 `/signin-with-chatgpt?return_to=/` 模拟登录；生产认证由 Sites 平台处理。生产部署不能直接暴露开发服务器。

```bash
npm test
npm run typecheck
npm run build
# 启动本地开发服务器后：
npm run test:http
```

单元测试覆盖权限隔离、原子审核、版本冲突、历史保留、emoji 坐标、模型错误、v3 校验和 Excel 往返；HTTP 冒烟测试覆盖真实本地 D1 与路由。浏览器自动化连接不可用，本次未完成视觉与文件选择器端到端验证。

## 部署

当前实现使用 Sites 托管的 Cloudflare Workers、D1、ChatGPT 登录，保留 `.openai/hosting.json` 和 starter 的 `sites()` 构建集成。通过 Sites 工作流同步源码、打包构建、应用迁移并部署。新部署保持仅所有者可访问；公开分享需要单独调整访问范围。复制项目建立新站点时，应注册自己的 Site 并替换 `project_id`，不要向本仓库所绑定的站点发布。

可选运行时变量见 `.env.example`。密钥必须由部署环境注入，不能写入托管清单、Git 或客户端包。仅用浏览器输入密钥也可运行，无需把密钥放进环境。

接口和数据格式见 [API-CONTRACT.md](API-CONTRACT.md)。理论规范的原始版本在仓库 `plugins/halliday-sfl-analysis-skill` 下；本站没有修改已安装的 Codex 插件。
